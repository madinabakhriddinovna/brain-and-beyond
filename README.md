# Brain and Beyond

Notes on the brain, science, and being human. By Madina Bakhriddinovna.

## Files

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `dreams.html` | What your brain does when you dream |
| `itch.html` | Why scratching makes it itch more |
| `change.html` | Why change feels like a threat |
| `people.html` | Why we are different people around different people |
| `script.js` | All the magic: neurons, music, glowing nerve, flip card, "you" neuron |
| `favicon.svg` | The little neuron icon in the browser tab |

No build step, no server code. Open `index.html` in a browser to see it.

## Put it online (free, with GitHub + Vercel)

1. On GitHub, create a new repository called `brain-and-beyond`.
2. Upload all these files to it (Add file → Upload files).
3. Go to vercel.com, sign in with GitHub, click **Add New → Project**, pick `brain-and-beyond`, and click **Deploy**.
4. In a minute you get a free link like `brain-and-beyond.vercel.app`.
5. Later: buy your domain and add it in Vercel → Project → Settings → Domains.

## Add a new story

Copy `itch.html`, rename it (for example `memory.html`), change the title, text and sources, and add a card for it on `index.html`.
